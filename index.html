Project Overview

CDW MarketShop is a cloud-integrated marketplace application developed with React Native, Expo, AWS serverless technologies, and Stripe.

This portfolio highlights the cloud architecture, API integrations, infrastructure configuration, and engineering challenges addressed during development.

AWS Cloud Technologies

AWS Lambda

Serverless backend functions for application operations.

Amazon API Gateway

HTTP API integration between frontend and backend services.

Amazon S3

Product image upload and retrieval workflows.

Amazon Cognito

User authentication and account management.

Amazon DynamoDB

Cloud-based application data storage.

Terraform

Infrastructure configuration using Infrastructure as Code.

GroceryMate — AWS Three-Tier Architecture

GroceryMate is a cloud infrastructure project designed around a three-tier architecture on AWS, using Terraform for Infrastructure as Code.

Web Tier

Frontend infrastructure for customer-facing grocery browsing and ordering workflows.

Application Tier

Amazon EC2 and load-balancing architecture designed to support application services.

Database Tier

Amazon RDS with PostgreSQL for relational application data storage.

Terraform Infrastructure

Modular Terraform configuration for AWS infrastructure provisioning and management.
